# Model and media rights / 模型与媒体权利

本仓库只发布原创编排代码、合同示例和离线测试夹具。真实角色参考图、成片、
音轨、字幕截图、ASR 原始响应、会话缓存和平台发布记录均不随仓库发布。

Before publishing any generated asset, verify all of the following with the
relevant provider and rights holder:

1. The provider terms permit the intended generation, redistribution, and
   commercial use.
2. Every reference image, voice, soundtrack, font, and user-provided input has
   a documented license or written permission.
3. No personal data, account identifiers, API responses, session IDs, or
   private browser/cache files are present.
4. The public repository records provenance and the exact license for any asset.

The example character contract intentionally contains no image bytes and marks
the references as placeholders. “Fictional” does not by itself prove that a
model output or a source image may be redistributed.
